# Contributing

## RFC-first requirement

Breaking schema changes require an RFC update/approval before merge.

## Pull Request Checklist

- [ ] Scope is focused and implementation-aware.
- [ ] Schema-impacting changes reference relevant RFC sections.
- [ ] Breaking changes include RFC-first evidence.
- [ ] Tests are added/updated where applicable.
- [ ] Documentation is updated to match code behavior.
- [ ] Non-final policy parameters are marked as TBD by governance/policy.

## Test and docs requirements

- Run repository lint, typecheck, and tests before requesting review.
- Keep documentation and TypeScript interfaces aligned.
- Include migration/backward-compatibility notes for schema-affecting changes.
